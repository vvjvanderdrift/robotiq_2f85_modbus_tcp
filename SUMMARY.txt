================================================================================
REGISTER MAPPING (FROM ROBOTIQ MANUAL):
================================================================================

COMMAND REGISTERS (Robot Output - 0x03E8 / 1000):
  Byte 0: ACTION REQUEST (rACT, rGTO, rATR, rARD)
  Byte 1: RESERVED
  Byte 2: RESERVED
  Byte 3: POSITION REQUEST (rPR)
  Byte 4: SPEED (rSP)
  Byte 5: FORCE (rFR)
  Bytes 6-15: RESERVED

STATUS REGISTERS (Robot Input - 0x07D0 / 2000):
  Byte 0: GRIPPER STATUS (gACT, gGTO, gSTA, gOBJ)
  Byte 1: RESERVED
  Byte 2: FAULT STATUS (gFLT, kFLT)
  Byte 3: POS REQUEST ECHO (gPR)
  Byte 4: POSITION (gPO)
  Byte 5: CURRENT (gCU)
  Bytes 6-15: RESERVED

================================================================================
USAGE EXAMPLE:
================================================================================

from robotiq_2f85_modbus_tcp import Robotiq2F85Gripper

# Connect
gripper = Robotiq2F85Gripper('192.168.1.100')
gripper.connect()

# Activate
gripper.activate()

# Move to position
gripper.goto_position(100, speed=100, force=50)
gripper.wait_for_motion_complete()

# Get status
status = gripper.get_status()
print(f"Position: {status.g_po}, Current: {status.g_cu}")

# Close
gripper.close()

# Disconnect
gripper.disconnect()
